# 프로그램 세팅 가이드

## 추천 기술 스택

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### 상태 관리
- React useState로 시작
- 필요 시 Zustand 추가

### AI API
- OpenRouter API 사용
- 무료 또는 저렴한 모델로 시작
- API Key는 .env에 저장

### 배포
- Vercel

## 프로젝트 생성 명령어

```bash
npm create vite@latest message-guard -- --template react-ts
cd message-guard
npm install
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

## Tailwind 설정

tailwind.config.js

```js
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

src/index.css

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## 환경 변수

.env

```txt
VITE_OPENROUTER_API_KEY=your_api_key_here
```

## 실행 명령어

```bash
npm run dev
```

## 빌드 명령어

```bash

```
