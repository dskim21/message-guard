# Message Guard

AI 기반 메시지 초안 및 검수 웹앱입니다.

사용자가 메시지를 보내야 하는 상황, 목적, 원하는 톤을 입력하면 AI가 바로 사용할 수 있는 메시지 초안을 생성하고, 오해 가능성이나 표현 리스크를 함께 점검해줍니다.

## 프로젝트 목적

사람들은 메시지를 보내기 전에 내용보다 표현 때문에 더 많이 고민합니다.

예를 들어 다음과 같은 상황이 있습니다.

- 상사에게 연차를 요청해야 할 때
- 친구와의 약속을 취소해야 할 때
- 거래처에 일정 지연을 사과해야 할 때
- 팀원에게 피드백을 줘야 할 때
- 거절 의사를 정중하게 전달해야 할 때

Message Guard는 이런 상황에서 사용자가 더 쉽고 안전하게 메시지를 작성할 수 있도록 돕습니다.

## 핵심 기능

- 상황 기반 메시지 초안 생성
- 목적 선택
- 톤 선택
- 짧은 버전 / 기본 버전 / 부드러운 버전 제공
- 오해 가능성 검수
- 표현 리스크 분석
- 개선 제안 제공
- 메시지 복사 기능
- 다시 생성 기능

## MVP 기능 범위

이번 MVP에서는 다음 기능에 집중했습니다.

1. 상황 입력
2. 메시지 목적 선택
3. 원하는 톤 선택
4. AI 초안 생성
5. 리스크 분석 결과 표시
6. 복사 기능
7. 로딩 및 에러 처리

로그인, 결제, 메시지 자동 발송, 히스토리 저장 기능은 MVP 범위에서 제외했습니다.

## 주요 고민

### 1. 단순 AI wrapper가 되지 않도록 하기
단순히 AI에게 메시지를 생성하게 하는 것이 아니라, 사용자가 메시지를 보내기 전에 확인해야 할 표현 리스크를 함께 제공하도록 설계했습니다.

### 2. 실제 복사 가능한 결과 만들기
AI 답변이 설명형 문장이 아니라, 사용자가 바로 복사해서 쓸 수 있는 메시지 형태로 나오도록 프롬프트를 설계했습니다.

### 3. 초급자도 유지보수 가능한 구조
MVP 단계에서는 복잡한 전역 상태 관리나 백엔드 구조를 도입하지 않고, React의 기본 상태 관리와 명확한 컴포넌트 분리로 구현합니다.
