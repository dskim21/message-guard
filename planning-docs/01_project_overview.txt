# 메시지 초안기 프로젝트 개요

## 프로젝트 이름
Message Guard

## 한 줄 소개
상황, 목적, 톤을 입력하면 메시지 초안을 생성하고, 보내기 전 오해 가능성까지 검수해주는 AI 메시지 초안 도우미.

## 핵심 컨셉
단순히 메시지를 대신 써주는 서비스가 아니라, 사용자가 메시지를 보내기 전에 생길 수 있는 오해, 공격적인 표현, 책임 회피처럼 보이는 문장 등을 점검해주는 서비스.

## 타깃 사용자
- 회사에서 정중한 메시지를 보내야 하는 직장인
- 친구, 지인, 연인에게 민감한 말을 해야 하는 사람
- 거절, 사과, 요청, 팔로업 메시지를 잘 쓰고 싶은 사람
- 말투 때문에 메시지 전송 전 고민이 많은 사람

## 핵심 문제
사용자는 메시지의 내용을 알고 있어도, 어떻게 표현해야 상대가 불쾌하지 않고 의도가 잘 전달될지 고민한다.

## 해결 방식
1. 상황 입력
2. 목적 선택
3. 톤 선택
4. AI 메시지 초안 생성
5. 오해 가능성, 표현 리스크, 개선 제안 제공
6. 짧게 / 기본 / 부드럽게 3가지 버전 제공

## MVP 핵심 가치
- 빠르게 쓸 수 있다.
- 결과가 실용적이다.
- 단순 생성이 아니라 검수까지 제공한다.
- 포트폴리오에서 AI UX 설계 능력을 보여줄 수 있다.
