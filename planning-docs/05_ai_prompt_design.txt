# AI 프롬프트 설계

## 목표
AI가 단순히 예쁜 문장을 만드는 것이 아니라, 실제로 복사해서 사용할 수 있는 메시지 초안과 검수 결과를 안정적으로 반환하도록 한다.

## 입력값
- situation: 사용자가 입력한 상황
- purpose: 메시지 목적
- tone: 원하는 톤

## 출력 형식
JSON 형식으로 반환한다.

```json
{
  "drafts": [
    {
      "label": "짧은 버전",
      "message": "..."
    },
    {
      "label": "기본 버전",
      "message": "..."
    },
    {
      "label": "부드러운 버전",
      "message": "..."
    }
  ],
  "review": {
    "riskLevel": "낮음 | 보통 | 높음",
    "possibleMisunderstanding": "...",
    "toneFeedback": "...",
    "improvementTip": "..."
  }
}
```

## 시스템 프롬프트 예시

너는 메시지 작성과 커뮤니케이션 코칭을 도와주는 전문가다.
사용자가 입력한 상황, 목적, 톤을 바탕으로 실제로 바로 보낼 수 있는 자연스러운 한국어 메시지를 작성한다.
과장된 표현, 지나친 사과, 공격적인 표현, 책임 회피처럼 보이는 표현을 피한다.
결과는 반드시 JSON 형식으로만 반환한다.
마크다운 코드블록은 사용하지 않는다.

## 사용자 프롬프트 예시

상황:
{{situation}}

메시지 목적:
{{purpose}}

원하는 톤:
{{tone}}

요청:
1. 메시지 초안을 3가지 버전으로 작성해줘.
2. 각 버전은 실제 메신저나 이메일에 바로 붙여넣을 수 있게 작성해줘.
3. 너무 장황하지 않게 작성해줘.
4. 상대가 오해할 수 있는 부분을 검수해줘.
5. 출력은 지정된 JSON 형식으로만 반환해줘.

## 프롬프트 설계 주의점
- AI에게 역할을 명확히 준다.
- 출력 형식을 고정한다.
- 너무 긴 답변을 막는다.
- 한국어 자연스러움을 강조한다.
- 실제 복사 가능한 문장을 요구한다.
- 검수 기준을 명확히 한다.

## 나중에 개선할 수 있는 점
- 상대와의 관계 입력 추가
- 메시지 길이 선택 추가
- 더 단호하게 / 더 부드럽게 수정 기능
- 영어 메시지 지원
- 히스토리 저장
