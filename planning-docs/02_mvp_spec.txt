# MVP 기능 명세

## MVP 목표
1~2주 안에 배포 가능한 수준의 AI 메시지 초안기 제작.

## MVP 포함 기능

### 1. 메시지 상황 입력
사용자가 메시지를 보내야 하는 상황을 자유롭게 입력한다.

예시:
- 상사에게 연차 요청을 해야 함
- 친구 약속을 취소해야 함
- 거래처에 일정 지연을 사과해야 함
- 팀원에게 피드백을 줘야 함

### 2. 메시지 목적 선택
버튼 또는 칩 UI로 선택한다.

목적 목록:
- 요청하기
- 거절하기
- 사과하기
- 감사하기
- 설득하기
- 팔로업하기
- 피드백하기
- 일정 조율하기

### 3. 톤 선택
버튼 또는 칩 UI로 선택한다.

톤 목록:
- 정중하게
- 친근하게
- 단호하게
- 부드럽게
- 프로페셔널하게
- 짧고 간결하게

### 4. AI 초안 생성
AI가 다음 3가지 버전을 생성한다.

- 짧은 버전
- 기본 버전
- 부드러운 버전

### 5. 메시지 검수
생성된 메시지에 대해 다음 항목을 분석한다.

- 오해 가능성
- 너무 차갑거나 공격적인 표현
- 책임 회피처럼 보이는 표현
- 너무 장황한 표현
- 개선 추천 문장

### 6. 복사 기능
각 메시지 카드에 복사 버튼을 제공한다.

### 7. 다시 생성 기능
같은 입력값으로 새 초안을 다시 생성한다.

## MVP 제외 기능
- 로그인
- 결제
- 메시지 자동 발송
- 카카오톡/메일 연동
- 히스토리 저장
- 팀 협업 기능
- 다국어 지원
- 모바일 앱

## MVP 성공 기준
- 사용자가 1분 안에 메시지 초안을 얻을 수 있다.
- 생성 결과가 실제로 복사해서 쓸 만하다.
- 단순 AI wrapper가 아니라 검수 UX가 보인다.
- README만 봐도 문제 정의, 기능, 기술적 고민이 명확하다.
