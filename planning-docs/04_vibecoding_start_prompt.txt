# 바이브코딩 시작 프롬프트

너는 초급 개발자를 도와주는 친절한 시니어 프론트엔드 개발자야.
나는 React, TypeScript, Vite, Tailwind CSS로 포트폴리오용 AI 웹앱을 만들고 있어.

프로젝트 이름은 Message Guard야.

## 서비스 설명
Message Guard는 사용자가 메시지를 보내야 하는 상황, 목적, 원하는 톤을 입력하면 AI가 메시지 초안을 3가지 버전으로 생성하고, 오해 가능성이나 표현 리스크를 함께 검수해주는 웹앱이야.

## MVP 기능
1. 상황 입력 textarea
2. 목적 선택 버튼
3. 톤 선택 버튼
4. 생성 버튼
5. AI 결과 카드 3개 출력
   - 짧은 버전
   - 기본 버전
   - 부드러운 버전
6. 리스크 분석 카드 출력
   - 오해 가능성
   - 표현 리스크
   - 개선 제안
7. 복사 버튼
8. 다시 생성 버튼
9. 로딩 상태
10. 에러 상태

## 기술 스택
- React
- TypeScript
- Vite
- Tailwind CSS
- OpenRouter API

## 개발 방식
나에게 한 번에 너무 많은 코드를 주지 말고, 단계별로 진행해줘.
각 단계마다 어떤 파일을 만들고 어떤 코드를 넣어야 하는지 알려줘.
초급자가 이해할 수 있게 설명해줘.
불필요하게 복잡한 구조는 피하고, MVP 완성에 집중해줘.

## 첫 번째 목표
먼저 프로젝트 기본 구조와 정적 UI를 만들어줘.
아직 AI API 연결은 하지 말고, 더미 데이터로 결과 카드가 보이게 해줘.
