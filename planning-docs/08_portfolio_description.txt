# 포트폴리오 설명 문구

## 짧은 소개
Message Guard는 사용자가 민감하거나 어려운 메시지를 작성할 때, 상황과 목적에 맞는 초안을 생성하고 표현 리스크를 검수해주는 AI 웹앱입니다.

## 문제 정의
많은 사람들은 메시지를 보낼 때 내용보다 말투와 표현을 더 많이 고민합니다.
특히 거절, 사과, 요청, 피드백처럼 상대방의 감정에 영향을 줄 수 있는 메시지는 잘못 표현하면 오해가 생길 수 있습니다.

## 해결 방법
Message Guard는 사용자가 입력한 상황, 메시지 목적, 원하는 톤을 바탕으로 3가지 메시지 초안을 생성합니다.
또한 생성된 메시지에 대해 오해 가능성, 표현 리스크, 개선 제안을 함께 제공하여 사용자가 더 안전하게 메시지를 보낼 수 있도록 돕습니다.

## 내가 집중한 부분
- 사용자가 바로 복사해서 쓸 수 있는 결과물
- 단순 생성이 아닌 검수 중심 UX
- 목적과 톤을 선택하는 직관적인 입력 흐름
- AI 응답을 안정적으로 다루기 위한 JSON 출력 설계
- 초급 개발자도 유지보수 가능한 컴포넌트 구조

## 기술적 포인트
- React와 TypeScript 기반 컴포넌트 설계
- Tailwind CSS를 활용한 반응형 UI
- OpenRouter API를 통한 AI 응답 생성
- 프롬프트 템플릿 분리
- AI 응답 JSON 파싱 및 에러 처리
- 복사 기능과 로딩 상태 구현

## 면접에서 설명할 수 있는 포인트
이 프로젝트는 단순히 AI API를 호출하는 앱이 아니라, 실제 사용자가 메시지를 작성할 때 겪는 불안과 오해 가능성을 줄이는 UX에 집중했습니다.
특히 결과 생성뿐 아니라 표현 리스크 분석을 함께 제공하여, AI 기능을 사용자 문제 해결 흐름 안에 녹여내는 것을 목표로 했습니다.
