# 한줄검수

> 보내기 전, 말투부터 확인해보세요.

감정이 섞인 메시지, 거절, 사과, 부탁, 돈/정산 요청처럼  
보내기 어려운 메시지를 **더 자연스럽고 덜 부담스럽게 다듬어주는 AI 메시지 코치 서비스**입니다.

<br />

## 프로젝트 소개

**한줄검수(Message Guard)** 는  
"이 말 괜찮을까?" 고민되는 순간을 줄여주는 서비스입니다.

사용자가 상황과 감정을 입력하면:

- 자연스러운 메시지 초안 3개 생성
- 말투/오해 가능성 검수
- 더 부드러운 표현 추천

을 제공합니다.

단순 문장 생성이 아니라,

> **관계를 덜 어색하게 만드는 커뮤니케이션 도우미**

를 목표로 했습니다.

---

## 주요 기능

### 1. 상황 기반 메시지 초안 생성

거절 / 사과 / 부탁 / 돈·정산 상황 등  
민감한 메시지를 자연스럽게 다듬어줍니다.

예시:

- 친구 약속 취소
- 돈 보내달라고 하기
- 정산 리마인드
- 부탁 메시지
- 어색한 대화 시작

---

### 2. 감정 기반 말투 조정

현재 감정을 선택하면 말투가 달라집니다.

예:

- 😥 미안함
- 😤 답답함
- 😐 어색함

같은 상황이라도 감정에 따라 다른 표현을 제공합니다.

---

### 3. AI 말투 검수

메시지에 대해:

- 오해 가능성
- 말투 온도
- 조심하면 좋은 표현
- 추천 한 줄

을 함께 제공합니다.

---

### 4. 돈/정산 메시지 특화

민감한 정산 메시지를:

> 너무 정색하지 않게  
> 너무 약하지도 않게

조절할 수 있도록 설계했습니다.

---

### 5. AI 실패 시 fallback 처리

무료 AI 모델이 불안정하거나 실패할 경우,

서비스가 멈추지 않도록  
**템플릿 기반 예시 결과를 자동 제공**합니다.

## 실행 방법

### 1. 프로젝트 설치

```bash
npm install
```

### 2. 환경변수 설정

루트 경로에 `.env` 생성

```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```

### 3. 개발 서버 실행

```bash
npm run dev
```

## 프로젝트 회고

이 프로젝트는

> “메시지 하나 보내는 것도 어렵다”

는 문제에서 시작했습니다.

특히 돈/정산, 거절, 부탁처럼  
관계가 어색해질 수 있는 순간을  
조금 더 부드럽게 만들어주는 경험을 목표로 개발했습니다.

무료 AI 모델의 한계(429, 품질 편차)를 경험하며

> 실패해도 서비스가 멈추지 않는 UX 설계

의 중요성을 배울 수 있었습니다.
